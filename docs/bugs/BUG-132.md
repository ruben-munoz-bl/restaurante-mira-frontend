# BUG-132 — El menú desplegable izquierdo de Admin baja de más

- **Zona:** admin
- **Prioridad:** media
- **Estado:** pendiente
- **Asignado:** claude

## Pasos para reproducir
1. Entrar en `#/admin`.
2. Desplegar/contraer el menú izquierdo y observar su altura.

## Resultado esperado
El menú ocupa su altura natural (o la del contenido) sin estirarse verticalmente hacia abajo.

## Resultado actual
El menú sigue bajando (se estira más allá de sus elementos).

## Notas / capturas
Hallazgo del usuario. Revisar alturas/`flex`/`min-height` del sidebar de admin.
