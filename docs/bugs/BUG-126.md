# BUG-126 — Avatar de MiraAI: se ve un cuadrado blanco dentro del círculo en modo oscuro

- **Zona:** mira/tema
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** claude
- **Rama:** fix/claude-tanda4

## Pasos para reproducir
1. Activar el modo oscuro.
2. Abrir el chat de MiraAI (MIRASI) y observar el círculo del avatar.

## Resultado esperado
El círculo del avatar sale todo blanco (o con la forma redondeada limpia), sin artefactos.

## Resultado actual
Se aprecia un efecto extraño: un cuadrado blanco sobre el círculo negro (la imagen no está recortada al círculo o su fondo no enmascara).

## Notas / capturas
Hallazgo del usuario: «que el círculo del asistente sea siempre blanco, ya que al tener fondo el gif se nota el recuadro». El gif es `/mochi.gif`, usado en el launcher flotante (`.mira-launcher`), el botón del header (`.header-mira-btn`), el header del panel (`.mira-header-logo`) y el tab de BottomNav.

## Solución

Causa: los círculos usaban `background: var(--papel)`, que en oscuro es `#1c201c` (casi negro); el gif lleva fondo propio y se dibujaba como un recuadro claro sobre el círculo oscuro. Archivo: `src/components/mira/mira.css`. `.mira-launcher` y `.header-mira-btn` pasan a `background: #fff` fijo (en claro no cambia: `--papel` ya era `#fff`) y el borde del punto `.mira-launcher-dot` a `#fff` para que encaje con el círculo. Verificación: `npm test` 167/167 y `npm run build` OK en `fix/claude-tanda4`. Pendiente de revisión.
