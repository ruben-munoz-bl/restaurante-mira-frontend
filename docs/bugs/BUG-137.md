# BUG-137 — Verificar el correo lleva a la página de restablecer contraseña

- **Zona:** auth (web)
- **Prioridad:** alta
- **Estado:** pendiente
- **Asignado:** —

## Pasos para reproducir
1. Registrarse con un correo nuevo.
2. Abrir el enlace del correo de verificación.

## Resultado esperado
Se verifica el correo (`applyActionCode`) y se muestra «Correo verificado».

## Resultado actual
Abre la web en `#/restablecer` y pide una nueva contraseña.

## Notas
Hallazgo del usuario. Causa probable: en Firebase Auth, la URL de acción de las plantillas apunta a `#/restablecer` para todas las acciones. `Restablecer.jsx` solo extrae `oobCode` y no mira `mode` (`verifyEmail` / `resetPassword` / `recoverEmail`). Arreglo propuesto: un gestor de acciones que bifurque por `mode` (verifyEmail → `applyActionCode` y mensaje; resetPassword → el formulario actual). Revisar también qué envía la app móvil.
