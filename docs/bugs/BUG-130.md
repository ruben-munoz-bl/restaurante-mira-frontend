# BUG-130 — Los modales y desplegables se centran en la página y no en la pantalla

- **Zona:** ui-global
- **Prioridad:** alta
- **Estado:** pendiente
- **Asignado:** claude

## Pasos para reproducir
1. Abrir una página con scroll (p. ej. landing larga o ficha).
2. Bajar por la página y abrir un modal o desplegable.

## Resultado esperado
El modal/desplegable queda centrado respecto a la ventana (pantalla), siempre visible.

## Resultado actual
Aparecen centrados respecto al documento: se ven a media altura o fuera del viewport si la página está scrolleada.

## Notas / capturas
Hallazgo del usuario (afecta a varios modales). Causa típica: `position: absolute` en vez de `fixed` (o contenedor con `transform`). Buscar modales comunes en `src/components/` y unificar el patrón; toca a muchos componentes, hacer cambio transversal mínimo.
