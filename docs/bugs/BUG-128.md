# BUG-128 — Los iconos de admin tardan en cargar

- **Zona:** admin
- **Prioridad:** media
- **Estado:** pendiente
- **Asignado:** claude

## Pasos para reproducir
1. Entrar en `#/admin` (o recargar con Ctrl+F5).
2. Observar la carga inicial de los iconos del panel.

## Resultado esperado
Los iconos aparecen de inmediato (inline o precargados), sin parpadeo ni huecos.

## Resultado actual
Los iconos tardan en aparecer (se ven huecos o placeholders un momento).

Hallazgo del usuario. Determinar si son SVG inline, fuente de iconos o assets lazy; valorar precarga o import estático.
