# BUG-136 — Al volver a entrar en una sección, el scroll no empieza arriba

- **Zona:** general (web y app)
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** claude

## Descripción
Al salir de un apartado y volver a entrar, se conserva la posición de scroll anterior en lugar de empezar arriba.

## Solución
- **Web:** el navegador restauraba el scroll al ir atrás (`history.scrollRestoration = 'auto'`), por encima del `scrollTo(0, 0)` del `hashchange`. Ahora es `'manual'` (App.jsx). Además, en el panel admin las secciones cambian con `replaceState`, que no dispara `hashchange`; `ir()` ya hace `scrollTo(0, 0)`.
- **App:** el Stack de expo-router mantiene montada la pantalla anterior con su scroll. `AppShell` usa `useFocusEffect` para llevar el ScrollView arriba (y volver a mostrar la cabecera) cada vez que una sección recibe el foco.
- Archivos: `src/App.jsx`, `src/components/ops/OpsPanel.jsx`, `mobile/src/components/shell/AppShell.jsx`.
- Verificación: `npm test`, `npm run build` y `npx expo lint`.
